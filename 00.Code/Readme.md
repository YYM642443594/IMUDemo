# 00.Code — CAN 统计工具 (can_stat)

Linux SocketCAN 被动统计工具：监听 `can0` 上 CAN ID **0x091~0x098** 的标准数据帧，实时统计每个 ID 的帧间隔与频率（Hz）。**只收不发，不干扰总线。**

## 文件说明

| 文件 | 说明 |
|---|---|
| `can_stat.c` | 统计程序源码（纯 C，依赖 linux/can.h，无第三方库） |
| `run.sh` | 一键脚本：gcc 编译 → 检查接口 UP → 运行 |
| `.gitignore` | 忽略编译产物 `can_stat` 二进制 |

## 编译运行

```bash
./run.sh              # 默认 can0，一直跑到 Ctrl-C
./run.sh can0 10      # 统计 can0，跑 10 秒后自动打印汇总退出
# 等价手动操作: gcc -O2 -Wall -o can_stat can_stat.c && ./can_stat can0 0
```

## 实时表格字段说明

终端每 1 秒原地刷新一次（管道/重定向输出时每 5 秒打印一次）：

| 字段 | 单位 | 说明 |
|---|---|---|
| `ID` | — | CAN 标准帧标识符，范围 0x091~0x098（内核级过滤器，只收这 8 个 ID） |
| `帧数` | 帧 | 本次统计开始以来收到的该 ID 数据帧总数 |
| `平均Hz` | Hz | 平均频率 = (帧数−1) ÷ (首帧时刻→末帧时刻的时间跨度)，全程平均 |
| `瞬时Hz` | Hz | 最近 1 秒滑动窗口内的帧率，反映当前实际节奏（对比平均Hz可发现断流/变速） |
| `当前ms` | ms | **当前帧时间戳 − 上一帧时间戳**（该 ID 最近一次相邻两包的差值），每收到一帧即更新 |
| `平均间隔ms` | ms | 所有相邻帧间隔的算术平均值 = 总间隔和 ÷ (帧数−1) |
| `最小ms` | ms | 统计期间相邻帧间隔的最小值（帧间隔抖动下界） |
| `最大ms` | ms | 统计期间相邻帧间隔的最大值（帧间隔抖动上界，可发现掉帧/卡顿） |

## 数据解析区字段说明

实时表格下方还有一块**数据解析区**（每秒随表格刷新），按协议文档 `01.Doc/用户协议.md` 3.3.2 节解析每个 ID **最新收到的一帧**：

| 列 | 说明 |
|---|---|
| `ID` | CAN 标准帧标识符，同上表 |
| `原始数据(B0~B7)` | 该 ID 最新一帧的 8 字节原始数据，B0 为 CAN 报文第 1 字节（协议中表格的"字节1"） |
| `解析值` | 按协议解释后的物理量；多字节数值均为**小端模式(intel)**，即低字节在前 |

各 ID 解析依据（单位见协议 3.3.2 数据定义表）：

| ID | B0~B3 | B4~B7 | 解析说明 |
|---|---|---|---|
| `0x091` | Timestamp 低 4 字节 | Timestamp 高 4 字节 | 8 字节 unsigned long long，设备上电以来的时间戳，单位 `us` |
| `0x092` | Roll 横滚角 | Pitch 俯仰角 | float，单位 `°` |
| `0x093` | Yaw 航向角 | Temp 温度 | float，单位 `°` / `℃` |
| `0x094` | q1 | q2 | float，四元数分量 |
| `0x095` | q3 | q4 | float，四元数分量 |
| `0x096` | X_Acc | Y_Acc | float，加速度，单位 `m/s²` |
| `0x097` | Z_Acc | X_Gyro | float，加速度/角速度，单位 `m/s²` / `°/s` |
| `0x098` | Y_Gyro | Z_Gyro | float，角速度，单位 `°/s` |

- 解析始终针对**最新一帧**（不是平均值）；DLC ≠ 8 时显示原始十六进制并提示非协议帧。

- 某 ID 还没收到过数据（或只收到 1 帧还无法算间隔）时，对应列显示 `-`。
- 时间戳取 `CLOCK_MONOTONIC`（用户态收包时刻），精度受内核调度影响，微秒级抖动属正常。

## 汇总字段说明

程序结束（Ctrl-C 或到时）后打印 `=== 汇总 ===`，每个 ID 一行：

| 字段 | 说明 |
|---|---|
| `N 帧` | 该 ID 收到的总帧数 |
| `平均 N Hz` | 全程平均频率，算法同表格 `平均Hz` |
| `当前间隔 N ms` | 收尾前最后一帧的"当前帧−上一帧"差值，同表格 `当前ms` |
| `平均间隔 N ms` | 全程平均帧间隔，同表格 `平均间隔ms` |
| `min / max N ms` | 全程最小/最大帧间隔，同表格 `最小ms`/`最大ms` |

## 判读参考

- 理想周期帧：`当前ms` 紧贴平均值小幅波动，`最小ms`/`最大ms` 对称包裹平均值。
- `最大ms` 明显大于平均值 → 存在掉帧或发送端卡顿。
- `瞬时Hz` 长期低于 `平均Hz` → 数据流变慢或已断流。
